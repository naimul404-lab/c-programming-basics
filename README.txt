C Programming Basics - Programs 43 to 50

Included programs:
43 - Dynamic memory allocation using malloc()
44 - Dynamic memory resizing using realloc()
45 - Writing to and reading from a text file
46 - Mini project: Calculator
47 - Mini project: Student marks and average
48 - Mini project: Number guessing game
49 - Mini project: Contact list (in-memory)
50 - Mini project: Library record system (in-memory)

How to compile (GCC):
    gcc filename.c -o program

How to run:
    ./program

On Windows:
    program.exe

Notes:
- Program 45 creates student-notes.txt in the program's current working directory.
- Programs 49 and 50 keep records in memory only; records are not saved after exiting.
- These are beginner learning examples. Compile and test each program before relying on it.
